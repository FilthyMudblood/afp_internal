# NeurIPS 2026 Agents in the Wild — 投稿包

NeurIPS 2026 AIWILD 短文已 **Reject**。本目录是改稿包，不是白皮书。

主张：CPL 是执行边界上的运行时刹车。主证据是 LangGraph Path A 开/关 + 真 tool（lookup / HTTP GET）：S1/S2 完成且不误伤，S3 深度 11 隔离，S4 在 burst entropy 0.96 拒掉。附录深度-only 表和 500 节点蒙特卡洛是 sanity check：**100% 是熔断不变量**（拒 >0.95，死亡 = load≥1），不是现场结果。消融仍写明熔断在扛活，CVP 在这个对手下不是生存必要条件。

下一投稿：**AAMAS 2027 Blue Sky**（摘要 11-05，全文 11-12 AoE，4 页 ACM 格式）。细节见 `SUBMISSION.md`。

## 编译

已编译稿：`paper/paper.pdf`。工作坊规定 references / supplementary 不计页。改稿后需重编，确认正文（到 Discussion）仍 **≤ 4 页**。不要求 NeurIPS checklist。

```bash
cd artifacts/neurips-aiwild-2026/paper
# 有 TeX Live 时
make
# 或
tectonic -X compile paper.tex
```

没有本地 TeX：把 `paper/` 整目录上传 Overleaf，主文件选 `paper.tex`。

## 匿名（必须）

投稿 PDF、附录、补充材料、代码链接都要匿名。

- 不要写 Aegis / AFP / 仓库名 / Zenodo DOI / 作者真名
- 论文里系统名是 **CPL**（Consequence Persistence Layer）
- 不要附 GitHub。审稿人用标题搜到公开白皮书不一定 desk reject，但自引必须写成第三人称，且本次稿件不要放可识别链接

## 和白皮书的差别（有意的）

1. 学术口吻，不再用协议宣言腔。
2. 对上 admission control / circuit breakers、AgentDojo、AI Control、MCP 安全；主实验是 LangGraph Path A + 真 tool，不是蒙特卡洛。
3. 消融诚实：breaker-only = 100%，viability-only ≈ baseline。
4. 明确说这不是 in-the-wild 现场评测；LangGraph 轨迹不是 MCP / 注入评测。

录用后再把 CPL 改回 AFP，见 `AUTHOR_NOTES.md`。
